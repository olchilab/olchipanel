# 자료에 맞는 표현을 선택하는 OlchiPanel — 제품 방향

2026-09-19 사용자 명시. 이 문서는 향후 방향이며 전체 기능의 구현 완료를 뜻하지 않는다.

## 사용자가 원하는 흐름

엑셀 시트·CSV 같은 자료를 넣으면 OlchiPanel 스킬이 자료의 구조와 작업 목적을 파악하고, 적절한 그래프·표·상황판을 선택해 패널 안에 보여준다. 에이전트와 대화하면서 표현을 바꾸고, 분석 결과를 노트·플랜·결정·세션 인계와 연결한다.

제품의 큰 줄기는 특정 센서 그래프나 고정 대시보드 하나가 아니라, 자료에 맞는 표현을 선택하고 작업 맥락 안에서 계속 사용하는 것이다.

## 이번 대회 데모 범위

- 미리 준비한 가상 웹사이트 자료: 2026-08-01~09-19, 50일의 방문자 수·매출.
- X축은 날짜, Y축은 현재 선택한 지표. 방문자 수와 매출은 단위가 다르므로 지표를 전환해서 본다.
- Panel 내부 `자료 분석` 탭. 기존 Studio 테마에 맞추고 OlchiScope 그래프·구간 선택·확대·이동 로직을 재사용한다.
- 날짜 구간을 고르면 실제 샘플 값으로 일평균·최소·최대를 계산한다. 매출은 구간 합계, 방문자 수는 분석 일수를 제공한다.
- 선택 결과를 샘플 노트와 추가 확인 플랜에 반영하고 재방문 시 다시 볼 수 있다. 실제 사용자 노트나 플랜을 쓰지 않는다.
- 파일 업로드·엑셀 해석·스킬의 자동 차트 선택·실제 AI 호출은 이번 구현에 포함하지 않는다.
- 임의 노트 편집·플랜 상태 편집은 앞선 사용자 결정대로 후속 작업으로 둔다.

## 향후 구체화할 계약

1. 자료를 받아 열·자료형·단위·날짜·누락값·집계 수준을 확인한다.
2. 작업 목적이 불명확하면 최소한의 질문으로 확인한다.
3. 스킬이 표현을 선택한다. 예: 시간 추이 → 선 그래프, 항목 비교 → 막대 그래프, 상세 값 → 표. 이는 향후 후보이며 아직 자동 선택 계약은 없다.
4. 패널은 선택된 표현을 렌더링하고 원자료·필터·집계 기준을 추적할 수 있게 한다.
5. 결과를 노트·할 일·결정으로 이어가고 다음 세션에서도 해석 기준을 확인한다.

기간별 방문자 합계를 기간 전체의 중복 제거 방문자 수로 표시하지 않는다. 방문자·매출의 동시 변동만으로 인과관계를 단정하지 않는다. 이번 예시는 원인을 확인할 추가 자료를 요청하는 플랜으로 이어진다.

## 현재 구현 근거

- `tools/championship/scope/`: 재사용한 그래프·방문자/매출 샘플·통계·Studio 표현.
- `tools/championship/fixtures.js`: 분석 결과를 샘플 노트·플랜에 반영.
- `test/championship-analysis.test.mjs`: 집계·날짜 경계·선택 결과 검증.
- `01_plan/AI-CHAMPIONSHIP-2026-DEMO-VERIFICATION.md`: 실제 브라우저 검수 범위와 한계.

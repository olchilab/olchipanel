# 상황 그래프 ImageGen 레퍼런스 — 승인 및 원본 구현

- 사용자 요청: 제출용 상황 그래프가 예쁘지 않으며 ImageGen으로 참고안을 만들어 상자와 연결 화살표를 개선한다. 공개 배포 보류는 유지한다.
- 작업 모드: production. 기존 Studio 색상·사이드바·작업명과 8개 노드/7개 부모-자식 관계를 유지하는 국소 그래프 디자인 변경.
- 원본: output/championship-submission-r2/03-work-graph.png.
- 생성 레퍼런스: output/graph-design-reference/graph-box-arrows-r1.png.
- 선택 상태: 사용자 승인. 앱 원본 구현 지시를 받아 public/index.html과 public/themes/studio.css에 적용했고 정적 데모도 같은 Studio 렌더러로 재생성했다.
- 사용자 목적: 목표에서 작업·분기·현재 행동까지 관계를 읽으며 노드를 이동하고 전체를 다시 맞춘다. 재방문 시 수동 좌표와 카메라의 기존 계약을 유지한다.
- 방향: 컴팩트하고 같은 열에서 정렬된 상자, 5~7px 모서리, 좌측 정렬 제목과 작은 상태, 둥근 직교 연결선·도착점 화살촉, 현재 작업의 절제된 황토색 강조. 보류는 점선 후보다.
- 피함: 과도한 그림자·둥근 알약·새 팔레트·겹친 연결선·방향 없는 선·형제 관계를 순차 의존성으로 잘못 표현하기.
- 레퍼런스 관찰: 8개 상자·7개 연결과 한국어 라벨이 보존되고, 완료/현재/보류가 구분된다. 생성 이미지의 약한 표면 질감은 CSS에 그대로 복제하지 않고 기존 Studio 평면 색을 유지한다. 화면 진행 상태 줄은 실제 앱에서 보존한다.
- 코드 확인: public/index.html에 graphArrow marker 정의가 있으나 renderJourneyGraph의 edge path에는 marker-end가 없다. 연결 방향은 실제 구현 시 marker 부착과 끝점 경계 계산으로 바로잡아야 한다.
- 구현 후 검수: 라이트·다크, 작은/큰 트리, 모든 상자 경계와 화살촉 방향, 노드 드래그 후 끝점, 키보드 이동, 맞춤·정렬·확대, 재방문 저장. 단순 생성 이미지로 기능 완료를 주장하지 않는다.
- 컴포넌트 선택: 기존 SVG 엔진을 유지하여 드래그·키보드·저장·맞춤 계약을 보존한다. 화살촉만 붙이는 안보다 좁아진 상자·곡선 모서리·상대 위치별 경계 연결까지 함께 구현했다. 외부 그래프 라이브러리 추가 없음.
- 검수: [실제 앱 증거](../output/graph-app-review/검수결과.md), [제출 R3](../output/championship-submission-r3/review.html). 공개 배포 보류.

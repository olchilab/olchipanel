- 검증: `test/graph-layout.test.js`의 높이 혼합 단계·간격·추가 작업·제목 줄바꿈, `test/ui-shell.test.js`와 `test/theme-renderer.test.js`의 저장 키 회귀.

## 2026-09-30 상황 워크플로우 보기 v7

- 최신 사용자 지시: 주 흐름은 왼쪽에서 오른쪽으로, 추가 작업은 그 단계 아래로 흐르게 한다. `map.tree`의 기록 순서와 부모 관계는 그대로 사용한다.
- 주 단계는 상단 한 줄에 좌→우로 놓고 오른쪽 방향으로 연결한다. 세부·분기·보류는 실제 부모가 속한 단계 열 아래에 놓는다. 첫 추가 작업은 부모 하단에서 자식 상단으로 곧장 내려가고, 같은 부모의 뒤따르는 추가 작업은 앞선 카드를 피해 옆 홈을 쓰되 화살표는 자식 상단으로 내려간다.
- 가로로 긴 흐름은 `맞춤`에서 전체 범위를 보이고, 읽기 어려울 만큼 작아지면 현재 위치로 초점을 옮긴다. 빈 `now`는 위치를 추정하지 않는다.
- 좌표 키는 `olchipanel.graph.layout.v7`이다. 이전 v6 수동 좌표는 보존하고 새 방향에 자동 적용하지 않는다. 이 배치는 기록된 작업 흐름이며 실제 실행 의존성의 증명이 아니다.

## 2026-09-30 상황 워크플로우 보기 v6

- 최신 사용자 지시: 상황 탭의 그래프 자리를 워크플로우 보기로 바꾸고 현재 하는 일이 어느 단계인지 표시한다. 트리·스택과 확대·이동·노드 조정 기능은 유지한다.
- `map.tree`가 정본이다. 루트의 일반 자식은 기록된 순서로 잇고, 중첩 단계·명시적 분기·보류는 부모에서 뻗는 옆 경로로 표시한다. 선은 실제 LangGraph 실행 추적이나 검증된 작업 의존성을 뜻하지 않는다.
- `now`는 해당 노드를 강조하고 주 경로의 단계 번호를 보여 준다. 종료·stale 세션은 '마지막 위치'로 표시한다. `now`가 없으면 위치를 추정하지 않고 현재 위치 버튼을 비활성화한다.
- 새 배치에는 `olchipanel.graph.layout.v6` 키를 사용한다. 기존 v5 수동 좌표는 보존하며 새 워크플로우에서 다시 위치를 조정할 수 있다.
- 작성 계약은 기존 `olchipanel-track`에 둔다. 새 스킬을 늘리지 않고 주 단계의 기록 순서, 세부·분기, 정확한 `now`를 설명한다. 이 변경은 실제 LangGraph 런타임 연동이 아니다.

## 이전 그래프 자동정렬 v5

- viewport는 고정 높이 대신 상황 패널에서 탭·진행 안내·도구를 제외한 남은 높이를 사용한다. 크기 관찰은 폭과 높이를 모두 확인한다.
- 같은 깊이의 상자는 해당 열 최대 너비를 공유해 좌우 경계를 맞춘다. 글은 좌측 정렬하고 상태는 하단 보조 정보로 둔다.
- 각 하위 트리의 실제 높이 합과 최소 24px 간격으로 공간을 먼저 확보한다. 열 사이 간격은 80px다.
- 부모는 첫 자식과 마지막 자식 중심의 중간에 배치하되 예약 공간을 넘지 않는다. 연결점은 상자 측면 중앙이며 같은 분기 묶음은 같은 수직 연결선을 사용한다.
- 정렬은 현재 데이터로 결정적으로 다시 계산한다. 반복해도 결과가 같아야 한다. 옛 수동 좌표 v4는 남기고 새 배치는 v5 키를 사용한다.
- 맞춤은 전체 경계와 여백을 실제 viewport에 넣는다. 최소 배율로 큰 트리를 강제로 잘라내지 않는다. 수동 확대와 이동은 유지한다.

검증: `test/graph-layout.test.js`의 크기 혼합 30개 트리(겹침·간격·열 경계·결정성·큰 트리 맞춤), `output/playwright/absorbed-graph0908.js`의 실제 앱 1280×800, 1280×620, 960×620, 1440×900 및 정렬 반복·라이트/다크 확인.

## 2026-09-19 앱 원본 그래프 개선

- 상자 기본 폭 240px, 긴 제목 최대 340px, 3줄 제한, Studio 제목 15px·상태 11px, 모서리 6px. 측정 폰트와 실제 Studio 폰트를 맞춘다.
- 부모-자식 관계를 그대로 유지하며 최대 12px 둥근 직교 연결선과 도착 경계의 화살촉을 사용한다. 현재 작업은 황토색, 보류·샛길은 점선이다.
- 수동 이동 후 좌우가 뒤집히면 좌우 포트를 바꾸고, 가로 간격이 부족하면 상하 포트를 사용한다. 수동으로 상자를 겹친 경우 자동 장애물 회피는 하지 않는다. 정렬로 겹침을 해소할 수 있다.
- v5 저장 키를 유지하여 기존 수동 위치를 보존한다. 정렬 버튼을 누르면 새 크기 기준으로 재배치한다.

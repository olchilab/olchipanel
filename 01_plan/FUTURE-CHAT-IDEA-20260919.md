# 올치패널 채팅 확장 아이디어

- 기록일: 2026-09-19
- 상태: 추후 개발 후보. 현재 구현하지 않음.
- 사용자 결정: 지금은 데모에 집중하고, 채팅 기능은 아이디어만 정리한다.

## 원하는 경험

올치패널 안에서 AI와 대화하고, 이후에는 친구를 추가하여 사람끼리도 채팅할 수 있게 한다.

## 추가 아이디어 — AI 세션을 패널 안으로 불러오기

- 사용자 추가 요청(2026-09-19): “나중에 올치패널 안에 AI 세션을 직접 불러와서 대화하면서 해도 좋을 것 같다. 어사이드처럼. 아이디어로만 정리.”
- 원하는 경험: OlchiPanel 안에서 AI 세션을 불러와 대화를 이어가면서 작업하고, 같은 공간에서 상황판·플랜·노트를 확인한다.
- 기존 AI 채팅 아이디어를 세션 연결 경험으로 구체화한 후보이며, 친구·사람 간 채팅과는 구분한다.
- “어사이드처럼”은 사용자 참고 표현으로 보존한다. 특정 제품의 구조나 API, 동일한 기능 지원을 확인한 것으로 해석하지 않는다.
- 추후 검토: 불러올 세션의 범위(진행 중/종료된 세션), 대화 이력·작업 맥락 연결 방식, 외부 에이전트와 패널 내 대화의 상태 동기화. 지원 AI·연결 방식·권한·화면 배치는 아직 정하지 않았다.
- 상태: 아이디어 기록만 완료. 현재 제출 데모·제출 문안의 구현 완료 기능에 포함하지 않으며 개발·API 연동은 착수하지 않는다.

## 확정된 아이디어

1. AI 채팅: 올치패널에서 AI와 대화할 수 있는 공간.
2. 사람 간 채팅: 친구를 추가하고 연결된 사람과 대화하는 기능.
3. 현재 데모 범위에서는 구현하지 않는다. 화면·서버·계정·친구 관계·메시지 전송을 이번 작업에서 추가하지 않는다.

## 추후 착수 시 정할 것

- AI 대화에 어떤 프로젝트 맥락을 연결할지, 어떤 AI를 사용할지.
- 친구 요청·수락과 1:1 대화를 먼저 만들지, 그룹 대화까지 포함할지.
- 대화 기록 보관, 알림, 차단·신고, 공유 범위.

위 항목은 검토 질문이며 확정 요구사항이나 착수 승인이 아니다. AI 채팅과 사람 채팅의 구현 순서·일정도 아직 정하지 않았다.

## 원문 의도

“AI와 채팅도 가능하고 나중에 사람과도 친구 추가해서 채팅 가능. 일단 추후에 개발할 것으로 정리만. 지금은 데모만, 아이디어만 정리.”

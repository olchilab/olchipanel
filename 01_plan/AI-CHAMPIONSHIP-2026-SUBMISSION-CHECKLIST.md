## 5. 입력 문안 초안 — 실제 업로드 전 검토용

최신 복사본은 `output/championship-submission-r3/제출문안.md`다. AI 활용 설명은 425자로 500자 이내이며 자료 분석 기능과 샘플 한계를 반영했다. 아래는 초기 설명 참고본이다.

### 서비스명

OlchiPanel — AI 에이전트 작업 상황판

### 한 줄 소개

긴 AI 대화를 다시 읽지 않아도, 목표·진행·갈림길·내가 결정할 일을 한눈에 확인하는 작업 상황판입니다.

### 해결하려는 문제

AI 에이전트에게 일을 맡길수록 대화와 작업이 길어집니다. 사용자는 지금 무엇을 하는지, 어떤 결정을 내렸는지, 어디서 막혔는지 확인하려고 이전 대화를 반복해서 읽습니다. 작업이 갈라지거나 세션이 바뀌면 이어갈 지점을 다시 설명해야 합니다.

### 해결 방식

OlchiPanel은 작업을 수행하는 에이전트가 MCP 도구로 목표, 단계, 분기, 결정과 요청을 구조화해 기록하도록 합니다. 사용자는 상황판에서 진행을 보고, 플랜에서 할 일을 확인하며, 요청에서 자신이 판단할 부분을 찾습니다. 저장된 작업 맥락은 다음 세션에서 이어받을 수 있습니다.

### 제품에서 AI가 하는 일

AI 에이전트가 작업 맥락을 해석하고 상태 변화를 구조화해 도구로 전달합니다. OlchiPanel은 이를 저장하고 실시간으로 시각화합니다. 패널 자체가 모델을 호출하는 서비스는 아니므로 별도 모델 API 키를 요구하지 않습니다. 연결한 에이전트의 이용 비용과 사용량은 별개입니다.

### AI 활용 방식 및 결과 — 500자 이내 후보

Codex를 활용해 구현과 검증을 진행했습니다. 제품에서는 작업 중인 AI 에이전트가 MCP 도구로 목표·진행 단계·분기·결정·요청을 구조화해 기록하고, OlchiPanel이 상태를 로컬에 저장해 실시간 화면으로 보여줍니다. 사용자는 긴 대화 대신 현재 진행과 자신이 판단할 일을 확인하고 다음 세션에서 맥락을 이어갈 수 있습니다. JavaScript·Node.js·MCP·HTTP/SSE·HTML/CSS·Electron을 사용합니다. 패널 자체의 모델 호출은 없으며 연결 에이전트의 비용은 별도입니다.

위 후보는 사용자 확인에 따라 제작 AI를 Codex로 명시했다. 구현·검증 범위는 현재 저장소 작업 근거에 맞추며, 효과를 수치로 주장하지 않는다.

### 제작에 사용한 AI — 사용자 확인 반영

- 실제 도구 이름: Codex(사용자 확인). 다른 AI 사용을 임의 추가하지 않는다.
- 맡긴 역할: [코드 구현 / 테스트 / 오류 분석 / 문서 정리 등 확인된 범위]
- 사람이 맡은 역할: [문제 정의 / 제품 방향 / UI 선택 / 결과 검수 등 실제 역할]
- 검증 방법: [실제 실행한 테스트·화면·설치 결과]

제품이 연결할 수 있는 에이전트 목록과, 이번 제품 제작에 실제 사용한 AI 목록은 구분한다. 쓰지 않은 도구나 확인하지 않은 모델명을 넣지 않는다.

### 차별점과 확장 방향

대화 전문 대신 현재 목표와 진행, 판단이 필요한 지점을 읽을 수 있게 합니다. MCP 도구 계약으로 에이전트와 화면을 연결하고 상태를 로컬에 저장합니다. 여러 에이전트 환경으로의 확장은 동일한 도구 계약을 바탕으로 하되, 호환성을 실제 확인한 환경과 향후 계획을 구분해 소개합니다.

이번 체험: 웹사이트 방문·매출 분석

준비된 하나의 프로젝트를 둘러보며 실제 사용 흐름을 확인합니다.

  1. 플랜에서 진행 확인할 일 카드를 옮겨 보세요.
  2. 자료를 분석하고 기록그래프를 살펴보고 노트를 남겨요.
  3. 다른 AI와 이어가기이전 맥락과 같은 자료를 확인해요.

가상 세션·자료를 사용하며 실제 AI는 호출하지 않습니다. 변경은 이번 체험에서만 유지되며, 새로 열면 처음부터 시작합니다.

샘플 체험Codex · Claude 가상 세션 · 새로 열면 처음부터 시작

내 작업에서 사용하려면

OlchiPanel은 AI 에이전트와 연결해 목표·진행·판단할 일·인계할 맥락을 확인하는 작업 상황판입니다.

Codex와 Claude는 가상 연결 세션입니다. 플랜 카드를 옮기고 노트를 직접 작성해 보세요. 입력은 이번 체험에서만 유지됩니다. 새로고침하거나 ‘처음부터’를 누르면 초기 상태로 돌아갑니다.

  1. GitHub의 설치 안내에서 자신의 환경과 에이전트에 맞는 방법을 확인합니다.
  2. 설치와 연결 후 에이전트에게 “이 프로젝트에서 OlchiPanel을 사용해 작업을 추적해 줘”라고 요청합니다.
  3. 다음 세션에서는 이전 패널의 맥락을 이어받도록 요청하고, 필요한 공통 노트를 다시 읽습니다.

이 체험은 현재 개발 중인 Studio 앱판을 기반으로 합니다. 공개 GitHub/npm 0.8.2의 화면·기능은 이 체험과 차이가 있습니다.

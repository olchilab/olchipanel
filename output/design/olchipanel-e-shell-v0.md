# OlchiPanel E shell v0

## 목적

현재 0.8.2 UI를 새로 꾸미지 않고 Electron 단일 창에 담아, 브라우저 PWA와 분리된 창·배율·아이콘 수명주기를 검증한다.

## 선택한 시각 기준

- 정본 화면: 현재 `public/index.html`과 `public/plan.html`.
- 새 상단바·카드·사이드 장식을 추가하지 않는다.
- OS 기본 제목 표시줄을 먼저 사용한다. 완전한 커스텀 프레임은 동작 안정화 뒤 별도 시안으로 판단한다.

## 피할 것

- 중앙 정렬 라운드 카드와 과도한 남색 면을 다시 추가하지 않는다.
- Electron 전환과 정보구조 개편을 한 번에 섞지 않는다.
- 표시 배율을 무시하려고 물리 픽셀을 강제하지 않는다.

## 수용 기준

- 두 번 실행해도 Electron 주 창은 하나다.
- 기존 6711 viewer를 재사용하며 다른 포트나 Chrome PWA를 열지 않는다.
- Node 통합을 끄고 격리·sandbox를 켠다.
- 앱 내부 확대는 100%로 고정하되 OS DPI는 존중한다.
- 마지막 정상 창 위치·크기를 사용자 데이터 폴더에서 복원한다.
- 0.8.2 viewer가 아니면 낡은 화면을 열지 않고 명확히 실패한다.
- 실제 Windows 배율 환경에서 제목·사이드바·플랜·그래프를 눈검수한다.

# E2 새 테마 레퍼런스 — 2026-09-08

상태: 외부 사례 회수 완료, 생성 시안 선택 대기. 구현 전 사용자 선택 필요. 기존 정본과 이전 E2 보관본은 수정하지 않는다.

목적: 컴퓨터·노트북에서 AI 작업의 현재 상태, 여정, 다음 행동을 쉽게 판단하고 Plan·기록·Note로 이동하는 작업 도구. 현재 기능·실제 데이터·그래프 정렬 v5는 유지한다.
핵심 행동: 세션 선택 → 현재 목표와 진행 확인 → 그래프/플랜/기록 전환 → 필요한 후속 행동.
기기: 1280×800 및 960×620 Windows Electron 앱, 마우스·키보드. 모바일은 범위 밖.
대표 상태: 현재 진행, 완료·다음 단계, 빈 플랜, 기록 읽음, 긴 제목, 미해결 요청, 재개 맥락, 연결 실패.

## 외부 레퍼런스

- Ableton Live: https://www.ableton.com/en/live/ — A안의 기능별 구획과 도구 중심 밀도 참고. 음원/에셋/제품 로고는 복제하지 않는다.
- Things: https://culturedcode.com/things/ — B안의 차분한 작업 목록과 글 중심 위계 참고.
- Nova: https://nova.app/ — 사이드바 도구 구분 후보로 검토했으나 일반 개발 편집기 느낌이 강해 주 방향으로 선택하지 않음.

## 제안

A 스튜디오 콘솔(추천): 차콜·웜그레이·앰버, 직선 구획, 명확한 작업대, 읽을 수 있는 밀도. 기존 청록/연한 배경과 확실히 구분된다. 무거운 네이비 대시보드·무의미한 pill·그림자·카드 겹침은 배제.
B 편집 데스크: 아이보리·잉크·벽돌색 포인트, 타이포그래피·얇은 구분선 중심. 읽기와 여백에 유리하지만 현재 밝은 화면과 변화 폭이 상대적으로 작다.

검수 기준: 작업명 우선, 선택·포커스 구분, 긴 제목 가시성, 그래프 카드 경계와 전체 가시성, 노트 편집 높이, 기록 최신순·요약 우선, 빈 상태 도구의 정직한 상태. 생성 이미지는 방향 선택 자료이며 기능·실화면 검증을 대체하지 않는다.
선택된 후보와 이유를 여기에 기록한 뒤 기존 컴포넌트를 재사용해 별도 E2로 구현한다.

생성 시안: `output/design/e2-theme-reference-comparison.png`.
자체 검토: 분위기 비교에는 사용할 수 있으나 생성 이미지의 선택 행 채움, 중앙정렬 노드, 상단 AI 도우미·검색·설정 및 진행률은 현재 기능/합의와 다르다. 구현 시 선택 행 채움을 제거하고 작업명 좌측 정렬과 기존 기능을 유지한다. 이미지에 그려졌다는 이유로 새 기능이나 임의 진행률을 추가하지 않는다. 아직 사용자 선택·승인되지 않았다.


## 선택과 구현
사용자: e2 e3로 만들고 열어놔. 두 안 모두 선택. E2=Studio Console, E3=Editorial Desk. 구현: desktop/comparison.cjs, public/themes/. 실제 주요 4탭 × 2크기 검수, JS 오류와 문서 넘침 없음. 그래프 측정 글꼴 일치 및 접힌 세션 아이콘 채움 제거 후 재검수.

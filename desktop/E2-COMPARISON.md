# 현재 E2·E3 테마 비교

2026-09-08 사용자가 두 레퍼런스를 모두 구현·실행하도록 선택했다.

- E: `npm run e` — 기존 정본
- E2: `npm run e2` — Studio Console, 차콜·앰버
- E3: `npm run e3` — Editorial Desk, 아이보리·벽돌색
- `desktop/theme-renderer.cjs`가 현재 정본 HTML에 `public/themes/` 스타일을 적용한다. 과거 `public/e2/` 보관본은 사용하지 않는다.
- 세 창은 실제 viewer 하나를 공유한다. Plan·Note 편집은 공유되고 창 위치·읽음·그래프 배치는 별도 프로필에 저장된다.
- 비교 창은 정본의 window lease를 가져가지 않는다. 각 테마별 단일 인스턴스이며 닫아도 공유 viewer를 종료하지 않는다.
- 1280×800, 960×620에서 상황·플랜·노트·기록 검수. 증거: `output/playwright/theme-*.png`. 제품 버전 0.8.2 유지.

# E2 비교 실행

**2026-09-08 종료:** 사용자 승인으로 E2를 정본에 흡수했다. `npm run e2`는 이제 정본 앱을 열거나 기존 정본 창을 앞으로 가져온다. 아래는 비교 당시 구조이며 `public/e2/`는 보관본이다. 새 수정은 `public/index.html`과 `public/plan.html`에 한다.

사용자 승인 2026-09-08. 제품 버전은 0.8.2이며 E2는 비교용 화면 이름이다.

- 기존 E: `npm run e`, `public/index.html` / `public/plan.html` 그대로 사용.
- E2: `npm run e2`, `public/e2/index.html` / `public/e2/plan.html` 사용.
- E2는 Electron 전용 HTTP 처리로 화면 두 개만 로컬 파일에서 읽고 나머지는 같은 실제 viewer API로 전달한다. 별도 서버나 가짜 API를 만들지 않는다.
- E2의 창 위치·읽음·그래프 배치는 별도 userData에 저장한다. Plan/Note와 세션 기록은 두 창이 공유하는 실제 데이터이므로 편집은 양쪽에 반영된다.
- E2는 기존 창의 단일 창 lease를 차지하지 않고 5초마다 실제 상태를 읽는다. 기존 E의 중복 방지는 유지된다.
- ①~⑥ 표시는 비교 검수용이다. 오른쪽 아래 E2 변경 안내에 각 번호의 의미가 있다.
- 기존 E와 E2를 각각 한 번 실행한다. E2를 다시 실행하면 기존 E2를 앞으로 가져온다. 비교 종료는 해당 창 닫기이며 MCP 또는 viewer를 종료하지 않는다.
- E2 채택·통합은 사용자 눈검수 후 결정한다. 원본 UI와 비교본은 검수 중 자동 동기화하지 않는다.

## E2 모드 (2026-09-08)
사용자 E2 선호 확인. 차콜·앰버 다크 기본값, 따뜻한 회색·짙은 앰버 라이트를 ◐ 버튼으로 전환한다. 별도 studio 테마 키에 선택을 저장하며 플랜도 동기화한다. 선택된 세션·사이드바·본문 탭은 왼쪽 3×18px 직사각형을 사용한다. 주요 4탭×2모드 실화면·새로고침 유지 검수, 증거 output/playwright/e2-mode-*.png.


## E2 현재 사용법 (2026-09-08)
- 사이드바 제목은 프로젝트 폴더명이며 20자 이내 한 줄로 표시한다. 전체 이름은 제목에 마우스를 올려 확인한다.
- 회색 원은 연결 안 됨, 초록 LED는 연결됨, 회전 스피너는 실제 응답 중이다. 응답 완료나 중단 뒤 연결이 유지되면 초록으로 돌아간다. 작업 완료 여부는 여정에서 확인한다.
- 응답 상태는 Orca의 실제 상태를 약 1.5초마다 확인한다. 동일 프로젝트의 여러 에이전트로 매칭이 모호하면 응답 중이라고 추정하지 않는다.
- OlchiPanel 제목 오른쪽 버튼으로 사이드바를 접고 편다. ◐ 버튼은 다크·라이트를 전환하고 선택을 저장한다.
- 상황·플랜·요청·기록·노트와 본문 탭의 사용법은 1초 hover 또는 키보드 포커스로 확인한다. 상시 안내를 최소화하되 실제 진행·오류는 숨기지 않는다.
- 상단 20자 목표는 현재 목적, 여정은 단계, 기록은 의미 있는 변경·결정·검증이다. 연결 LED를 켜기 위해 여정 상태를 바꾸지 않는다.

LED 추가 기준: 연결된 상태에서 마지막 활동 후 1시간 이상이면 노란불. 세션 시작 시각이 아니라 패널 갱신과 매칭된 Orca 활동의 최신 시각을 사용한다. 응답 중 스피너와 연결 끊김 회색이 우선한다.
